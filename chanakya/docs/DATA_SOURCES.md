# CHANAKYA — Data Source Research (India public affairs)

Researched 10 Nov 2026. Covers access method, reachability, licensing and integration plan for
each source CHANAKYA needs. **Licence findings are research notes, not legal advice.**
Get them confirmed by counsel before commercial launch.

## 0. Key finding: geo-blocking

From a non-Indian cloud IP (this build environment), several `gov.in` hosts **drop the TLS
connection**: data.gov.in, egazette.gov.in, erajyapatra.karnataka.gov.in, cea.nic.in. These
hosts were reachable: prsindia.org, pib.gov.in, sansad.in, mnre.gov.in, eci.gov.in (redirect)
and Wikidata.

**Consequence:** connectors for geo-blocked portals must run from an Indian region:
- Vercel Functions pinned to `bom1` (Mumbai), invoked by Vercel Cron, or
- a worker in AWS `ap-south-1` / GCP `asia-south1`.

The Supabase project (SamaPatra) is already in `ap-south-1`.

## 2. What is in the database snapshot today

Generated by `chanakya/ingest/collect.mjs` and written to `supabase/seed/real_corpus.sql`. The
raw records with provenance are in `data/snapshot/*.json`. Every row records its source URL and
retrieval timestamp, and keeps the publisher's own identifier (PRS slug, PIB PRID, Wikidata QID).

- **PRS**: central bills and rules: title, PRS status, year, link.
- **PIB**: latest press releases (Hindi and English feeds): title, date, link.
- **Wikidata (CC0)**:
  - union ministries and departments
  - major political parties (with abbreviation, website and founding date)
  - Karnataka power stations with coordinates, capacity and operator, which become `public_project` entities for the map

## 3. Licensing rules implemented in code

1. `sources.license_status` defaults to `unreviewed`. A database constraint blocks
   `is_active = true` until `license_status` is open/permitted **and** `license_reviewed_at` is set.
2. For any source without a clear reuse grant we store **bibliographic metadata only**
   (title, date, identifier, status, URL) and link out. Never body text or PDFs.
3. Wikidata (CC0) is the only source currently marked `open_license` and active.
4. Personal data: people only in a documented public capacity (`entities.public_capacity`
   is required for `person`). No voter rolls, no booth-level profiling.

## 4. Recommended integration order (Karnataka infra / energy / real estate)

1. **Runner in Mumbai.** Deploy the web app to Vercel with functions in `bom1` and add
   `/api/cron/ingest` (Vercel Cron, every 6h). This unblocks every geo-blocked portal.
2. **e-Gazette + Karnataka Gazette.** These are the legal source of truth. Store the PDF hash per
   version for change detection. Kannada OCR via Tesseract `kan`.
3. **Sansad questions.** Filter by ministry (Power, MNRE, Housing & Urban Affairs, Road Transport).
4. **data.gov.in.** Request an API key; pull project/budget datasets with the GODL attribution string.
5. **DataMeet boundaries + Wikidata coordinates.** Use them for the MapLibre Geo module.
6. **Sector ministries** (MNRE, CEA, MoHUA, MoRTH) and **Karnataka RERA / KREDL / KIADB**.

## 5. Open questions for counsel

- PIB: confirm the copyright policy overrides the RSS "All rights reserved" notice for commercial SaaS display of full releases.
- PRS: request a written licence for displaying their bill summaries (they are an independent NGO, not government).
- Gazette PDFs: confirm that mirroring official gazette PDFs inside a paid product is acceptable
  (Copyright Act s.52(1)(q) permits reproduction of Acts and official publications with conditions).
